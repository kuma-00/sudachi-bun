# sudachi-bun CLI仕様

## 基本

CLI エントリは `index.ts` です。

```bash
bun run index.ts <subcommand> [options]
```

現在の主機能は `tokenize` サブコマンドです。  
`build` / `ubuild` / `dump` は scaffold 状態です。

## tokenize

### 形式

```bash
bun run index.ts tokenize --dict-path <path-to-dic> --projection <projection> [options] [input-file ...]
```

### 必須引数

- `--dict-path <path>`
- `--projection <value>`

`projection` の対応値:

- `surface`
- `normalized`
- `dictionary_form`
- `reading`
- `dictionary_and_surface`
- `normalized_and_surface`
- `normalized_nouns`

### 任意引数

- `--config-path <path>`
- `--library-path <path>`
- `--mode <A|B|C>`
- `--wakati`
- `--all`
- `--output <path>` (`-` で stdout)
- `--text "<text>"`
- `--split-sentences`
- `--debug`
- `--resource-dir <path>`

## 入力解決ルール

優先順位:

1. `--text`
2. 位置引数ファイル
3. stdin（パイプ接続時）

制約:

- `--text` とファイル/ stdin の併用は不可
- ファイル指定と stdin の併用は不可
- 複数ファイルは指定順で連結して1入力として扱う

## 環境変数

- `SUDACHI_DICT_PATH` または `SUDACHI_DICTIONARY_PATH`
- `SUDACHI_CONFIG_PATH`
- `SUDACHI_FFI_PATH`
- `SUDACHI_FFI_DIR`

`--library-path` 未指定時のライブラリ探索順:

1. `SUDACHI_FFI_DIR`
2. `./sudachi-ffi/target/release`
3. `./sudachi-ffi/target/debug`

候補ファイル名:

- `libsudachi_ffi.<platform suffix>`
- `sudachi_ffi.<platform suffix>`

## 出力

- デフォルトは標準出力
- `--output <path>` でファイル出力
- `--output -` は標準出力固定
- `--wakati` は projection 適用後の surface を連結表示
- `--all` は取得可能なトークン情報を拡張表示

## デバッグ

`--debug` を指定すると stderr に診断ログを追加します。  
標準出力の解析結果フォーマットは維持されます。
