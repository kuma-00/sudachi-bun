# Task 04: CLI 入力処理（stdin / ファイル）

## 目的
`--text` 以外の入力経路（stdin / ファイル）を正式対応する。

## スコープ
- 引数ファイルパスからの入力
- パイプ入力（stdin）
- `--text` と他入力の優先順位・排他ルール

## 実装ステップ
1. 入力ソース判定ロジックを統一関数化
2. stdin が TTY かどうかを判定して待ち受け制御
3. ファイル複数指定時の処理方針を固定（逐次 or 結合）
4. 空入力時の終了コード/メッセージを規定

## 完了条件
- `echo ... | cli` が動作
- `cli input.txt` が動作
- `--text` とファイル/ stdin 競合時の挙動が仕様化されている
