# Task 01: CLI サブコマンド (`build` / `ubuild` / `dump`)

## 目的
`sudachi.rs` 相当の辞書系サブコマンドを CLI に追加する。

## スコープ
- `build` サブコマンドの追加（引数受け取りと実行導線）
- `ubuild` サブコマンドの追加
- `dump` サブコマンドの追加
- `--help` への表示と使用例追記

## 実装ステップ
1. CLI パーサに 3 サブコマンドを定義
2. 各サブコマンドのハンドラ関数を用意
3. 既存の辞書処理層に委譲（未実装なら TODO 明示）
4. コマンド別のエラー文言を統一

## 完了条件
- `build|ubuild|dump --help` が動く
- 未実装経路でクラッシュせずエラー終了できる
- 最低 1 つのスモークテスト（起動・引数解釈）を追加

## 依存
- なし
