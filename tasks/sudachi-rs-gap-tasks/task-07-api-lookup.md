# Task 07: API 辞書直接検索 (`lookup`)

## 目的
解析処理とは別に、辞書引き API を公開する。

## スコープ
- `lookup(surface)` 相当 API
- 候補語彙の基本情報返却
- 検索失敗時の空結果/エラー方針

## 実装ステップ
1. Tokenizer または Dictionary ハンドルに `lookup` 追加
2. 結果型（surface, pos, word_id など）を定義
3. 前方一致/完全一致の仕様を固定
4. CLI/デバッグ用途での利用導線を最低限追加

## 完了条件
- 代表語で候補が取得できる
- 未登録語で安定して空結果
- 辞書未初期化時のエラーが明確
