# Task 02: CLI 出力オプション (`--wakati` / `--all` / `--output`)

## 目的
CLI の出力形式制御を `sudachi.rs` に近づける。

## スコープ
- `--wakati`（分かち書き形式）
- `--all`（全フィールド出力）
- `--output <path>`（ファイル出力）

## 実装ステップ
1. オプション定義を追加
2. 出力フォーマッタを `normal|wakati|all` で切替
3. `--output` 指定時はファイルへ書き込み（未指定は stdout）
4. `--output -` を stdout 扱いにするか仕様決定して固定

## 完了条件
- 3 オプションが併用時も破綻しない
- ファイル出力時にディレクトリ不存在・権限エラーを扱える
- 代表ケースのスナップショットまたは文字列比較テスト追加
